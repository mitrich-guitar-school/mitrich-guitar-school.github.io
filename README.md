# Mitrich Guitar School

Индивидуальные уроки гитары в Батуми и онлайн · [mitrich-guitar-school.github.io](https://mitrich-guitar-school.github.io/)

Лендинг школы гитары Mitrich Guitar School — очные занятия в студии в Батуми (Грузия) и онлайн-уроки по видеосвязи через Google Meet. Обучение игре на акустической гитаре, электрогитаре и укулеле, с нуля и для продолжающих, для взрослых и детей.

## О школе

- Преподаватель: Дмитрий Кулешов
- Формат: очно (Батуми, ул. Хасана Хелимиши, 36) и онлайн
- Бесплатное пробное занятие
- Цены: разовое занятие $17, абонемент на 4 занятия $65, абонемент на 8 занятий $125

## Технически

Статический одностраничный сайт (чистый HTML/CSS/JS, без сборщиков), размещён на GitHub Pages.

- `index.html` — сама страница
- `images/` — фотографии (JPG + WebP)
- `sitemap.xml`, `robots.txt`, `llms.txt` — файлы для поисковиков и ИИ-краулеров
- `yandex-offers.xml` — фид предложений для Яндекс.Вебмастера
- Структурированные данные: Schema.org LocalBusiness, EducationalOrganization, FAQPage
